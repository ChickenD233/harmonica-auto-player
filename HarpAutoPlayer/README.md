# 口琴自动演奏器（《三角洲行动》）—— Windows 版

导入任意标准 MIDI 文件，从各（轨道, 声道）里选择**主旋律**，程序自动模拟键盘 + 鼠标，
把旋律“吹”出来（Windows 11 / Win10 x64 真实输出）。

> ⚠ **免责声明**：虚拟输入违反游戏规则，有账号封禁风险，请谨慎使用，风险自负。

---

## 用法

1. 打开 **MIDI 文件**（支持 .mid/.midi/.kar/.rmi）。
2. 在左侧**单击一行**作为主旋律。
3. 设好 **速度 / 移调 / 倒计时**（可拖进度条跳转、播放中实时变速/移调）。
4. 点 **▶ 播放**（或按开始热键），倒计时内切到游戏/测试窗口并装备口琴即可。

选项说明：勾选「**和弦只弹根音**」（默认开）后，MIDI 里同一时刻一起响的和弦只会吹最低的那个音（根音），
适合主旋律/伴奏含和弦的情况；取消勾选则恢复原始处理。

其他：
- 「**呼吸休止**」：连续吹奏约 8 秒后自动插入极短停顿（约 90ms）再继续，避免长时间连吹导致判定粘连；
- **记住设置**：速度/移调/倒计时/热键/两个选项自动记忆，下次打开恢复；
- **托盘后台**：点窗口 × 会隐藏到系统托盘（托盘菜单：显示窗口 / 开始 / 暂停 / 停止 / 退出），开始吹奏后窗口自动最小化；
- **本地日志**：写入 `%LOCALAPPDATA%\HarpAutoPlayer\play.log`（自动轮转，便于排查）；
- exe 自带图标与程序信息。

## 可演奏音域（与三角洲口琴一致）
- 键盘 **Z X C V B N M ，** = 中音 do re mi fa sol la si + 高音 do；
- 按住**左键** = 整排降到低八度；按住**右键** = 整排升到高八度；
- 右键+逗号 = 高高音 do；右键+**中键**+逗号 = 高高音 #do；每个键 + 中键 = 升半音；
- 范围：**低音 do ~ 高高音 #do**，超出部分自动**空拍**；
- 基准八度自动选择（音符最集中的八度）。

## 全局热键（游戏中直接生效，可自设）
- 默认：**F5** = 开始/继续，**F6** = 暂停/继续（界面里可改成 F1–F12 或“无”）。
- 使用系统低层键盘钩子，无需额外授权；离开软件后热键自动注销。

## 停止说明
点「停止」或关闭窗口时，程序会先把焦点还给正在播放的游戏窗口，再补发一次“全部松开”，
确保游戏一定能收到抬键（避免口琴一直响）。

## 本地钢琴测试台（调试用）
`口琴钢琴测试台.html`：单文件网页，按键/鼠标规则与三角洲完全一致，
范围 低音do~高高音#do，带发声与音名显示。用它验证自动演奏输出：
打开页面并点击获得焦点 → 光标放在页面内 → 运行本软件播放 → 页面会逐个亮音。
页面左键/右键/中键通过鼠标事件识别，因此**请保持光标在页面内**。

## 成品包
`release/HarpAutoPlayer-win-x64.zip`：自包含、无需安装 .NET，解压后双击 `HarpAutoPlayer.exe`。

## 构建
```bash
dotnet publish HarpAutoPlayer/HarpAutoPlayer.csproj -c Release -r win-x64 --self-contained true -o release/win-x64
```

## 技术说明
- UI：Avalonia(.NET 8)；MIDI 解析：DryWetMidi（UTF-8 轨道名）；
- 时间轴按“音乐时间”积分：速度可实时改、进度可拖拽跳转、移调可实时重映射；
- 输入：Windows SendInput；全局热键：WH_KEYBOARD_LL；
- 主旋律按单音处理，重叠自动切音；同键连音强制 ≥12ms 重触发间隔。
