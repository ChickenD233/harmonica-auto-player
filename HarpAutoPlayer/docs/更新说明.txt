口琴自动演奏器 v2.0.2

【本版】
新增：**MIDI 设备接入。** 接上 MIDI 键盘或打击垫，按键直接吹进游戏，不用先做谱。

- 位置：选项区最上面一行「MIDI 设备实时演奏」。
- 用法：勾上 → 在「设备」里选你的设备 → 切到游戏开始弹。
- 「基准八度」决定设备上哪个八度是口琴的中音 do。
- 「自动贴合音域」默认开：按最近弹过的音自动挑基准八度，跨几个八度弹也不会哑。
- 「力度下限」默认 1（不过滤）。设备有抖动或触后噪声时往上加。
- 状态文字实时显示最近一个音映射成了什么。停止时日志给出统计：
  收到多少音、多少超出音域、多少被后来的音顶掉。

音高怎么对：
  设备弹基准八度的 do..si → z x c v b n m。
  高一个八度 → 按住鼠标右键。低一个八度 → 按住鼠标左键。升半音 → 按住中键。
  最高只到高高音 #do。超出音域的音不发声，只记日志。
  口琴一次只吹一个音：同时按住多个键时，后来的音优先，前一个音被换掉。

修复：**2.0.1 部分曲子会缺音。**（听着像"按键按快了，少几个音"）

原因：音符在时间上重叠时，调度器为了让后一个音准时按下，会把前一个音的"抬起"
时刻一路提前到"按下"的同一时刻。于是前一个音变成零时长按键：按下和抬起落在同一帧，
游戏按帧采样时一帧都读不到，整段音被吃掉。

什么谱子会见得到：同刻起音、音尾压住下一个音头、密集打击乐轨。
（打击乐轨本来不能选作主旋律，但「合奏」把多轨压成一条线时也会出现同刻起音。）

改法：音符之间用"槽位"排开，而不是靠缩短前音让位。
- 与前音重叠（含同刻起音）的音顺延到前音之后，时值不变。
- 每次按下至少跨过一个帧点（帧长 + 1ms 余量）。
  这样一个零时长按键都不可能再出现。
- 修饰键提前量如果必然把本音推后，整段跟着后移，时值不变
  （旧写法只推"按下"不推"抬起"，时值会被压没）。

验证：
- 无界面时序台把事件表当成真实按键流，再用游戏口琴的采样规则去读。
  示例 1~4 加密集打击乐轨，在三个输入档位下全部"每个音都被采样到"，漏音 0。
- 合成极端谱面：同刻起音、长音重叠、同键 10ms/30ms 重触发、1/2~1/16 音符、
  首尾相接、八度来回切。三个档位下零时长按键 0 个，同键粘连 0 个。
- 回归对比：用 v2.0.1 的调度器做基线，正常谱面（无同刻起音、无重叠）
  15 组对比按键时刻**完全一致**。也就是说正常曲子的时序一点没变。

「时序诊断」同时多报一项：**时值被压到下限的音数**。正常曲子是 0。
不是 0 就说明这首谱挤得比该档位允许的最快速度还快，
把「输入兼容」换成「稳健」，或把速度降一点。
