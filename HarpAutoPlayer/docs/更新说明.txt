口琴自动演奏器 v2.0.1

【本版】
修复：F5 与 F7 不是相对移动，而是跳到固定位置。按 F7 总是跳到 5 秒。按 F5 总是回到开头。

原因：取当前位置时只在「正在演奏」的分支里读引擎时钟。其余情况读一个叫「起始位置」的变量。
刚打开歌曲时它是 0。所以 0+5 得 5 秒，0−5 被夹到 0。

改法：播放位置改为只有一个来源。
- 试听中：读试听时钟。
- 演奏中：读引擎时钟。
- 空闲时：读起始位置，并且每次定位都同步更新它。

现在三个状态都按当前位置相对移动。日志会写明「前进 5 秒：10.0 → 15.0 s」，方便核对。

实测（未播放，歌曲长 21 秒）：
  前进 5 秒：10.0 → 15.0 s
  后退 5 秒：15.0 → 10.0 s
  后退 5 秒：10.0 → 5.0 s
  前进 5 秒：5.0 → 10.0 s
  后退 999 秒：10.0 → 0.0 s（正确夹在开头）

附带修复：试听结束后，起始位置不再停留在旧值。

【卷帘怎么用】
标尺点 / 拖       定位播放位置
琴键栏点          选中该音高的全部音符（拖动连选多个音高）
拖音符中部        移动。多选时整组一起动，左右改时间、上下改音高
拖音符任一端      改长度。左端改头、右端改尾，音高不变
空白处拖          框选多个音符
空白处单击        定位，并清空选择
双击空白          加音；按住继续拖可一次定好长度
右键 / Delete     删除（右键拖动可连擦）
Ctrl+A / Esc      全选 / 清空选择
方向键            微调：左右按吸附步长，上下按半音；按住 Shift 加速
Ctrl+Z / Ctrl+Y   撤销 / 重做（保留当前缩放位置）
滚轮              以光标为锚点缩放
Shift+滚轮        左右平移
中键拖动          左右平移
缩小 / 放大 / 全曲  工具栏按钮，右边显示当前缩放百分比
试听              和「停止」一样大的独立按钮，只放声音不发按键
帮助              展开 / 收起右侧操作说明

颜色：绿 = 可演奏。灰 = 超出音域。

【热键】
F6  开始 / 暂停 / 继续 / 取消倒计时
F5  后退 5 秒（从当前位置）
F7  前进 5 秒（从当前位置）

三个键都能在界面里改，也可以关掉。
播放中用热键跳转，可能让游戏侧口琴卡音。遇到卡音请按「停止」后重新播放。

【换轨会丢改动】
切换主旋律轨，或改合奏勾选，手动改动会被丢弃，日志里会写明。
想保住改动，先导出 MIDI。

【用法】
1. 打开 MIDI。绿点是推荐的主旋律轨。
2. 在卷帘或进度条上点/拖，调到要开始的位置。右侧显示定位处的音。
3. 点「▶ 播放」或按 F6。
4. 倒计时结束前切到游戏，装备口琴。

【注意】
- 游戏用窗口化，不要用全屏独占。
- 输入法切英文。人物原地站好再开始。
- 在线对局使用自动输入有封号风险，自行斟酌。
