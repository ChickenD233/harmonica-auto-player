口琴自动演奏器 v2.0.1

【本版】
修复：F5 与 F7 不是相对移动，而是跳到固定位置。按 F7 总是跳到 5 秒。按 F5 总是回到开头。

原因：取当前位置时只在「正在演奏」的分支里读引擎时钟。其余情况读一个叫「起始位置」的变量。
刚打开歌曲时它是 0。所以 0+5 得 5 秒，0−5 被夹到 0。

改法：播放位置改为只有一个来源。
- 试听中：读试听时钟。
- 演奏中：读引擎时钟。
- 空闲时：读起始位置，并且每次定位都同步更新它。

现在三个状态都按当前位置相对移动。日志会写明「前进 5 秒：10.0 → 15.0 s」，方便核对。

实测（未播放，歌曲长 21 秒）：
  前进 5 秒：10.0 → 15.0 s
  后退 5 秒：15.0 → 10.0 s
  后退 5 秒：10.0 → 5.0 s
  前进 5 秒：5.0 → 10.0 s
  后退 999 秒：10.0 → 0.0 s（正确夹在开头）

附带修复：试听结束后，起始位置不再停留在旧值。

修复：**设置从来没保存过，所以「快速上手」每次都弹。**
现象：速度、移调、热键、输入兼容全都不记忆。每次启动都弹快速上手。
原因：发布开了裁剪（PublishTrimmed）。反射式 JSON 序列化依赖的元数据被裁掉，
运行时抛异常。而 Save 与 Load 原先都静默吞掉异常，所以一点提示都没有。
改动：设置读写改用**源生成的 JSON 上下文**（JsonSerializerContext），
编译期产出读写代码，不依赖反射。另外把两处静默 catch 改为写日志，以后再出问题能查到。
验证：用与发布完全一致的裁剪构建连跑两次。
第 1 次浮层可见，写入 settings.json（FirstRunDone=true）。
第 2 次浮层不可见。发布时的 AppConfig 相关 IL2026 裁剪警告从 2 条降为 0 条。

「快速上手」的文字同时精简：三段一句话，注意事项压成一行。
原来占满一屏，现在是一张小卡。

修复：**卷帘左键栏突然只剩 C4-C5，正在响的音符全部不显示。**
现象：声音正常，但卷帘上看不到音符，左键栏只有一个八度。
原因：一个声部都没勾选时，刷新流程会清空卷帘。而演奏引擎在开始播放时
已经把音符复制走了，所以声音继续，画面却空了。
左键栏的 C4-C5 是"音符列表为空"时的兜底区间，正好一个八度，所以看起来像音域变了。
改动两处：
- 已载入文件但没勾选声部时，不再清空卷帘，保留上一次的内容，并在日志写明。
  只有"根本没载入文件"才清空。
- 音符为空时，左键栏沿用上一次的音域，不再退回固定的 C4-C5。
提醒：如果又出现这个现象，请在日志里找「没有任何声部被勾选」这一行。

修复：**可见音域只有一个八度，超出可吹范围的音看不到、没法编辑。**
原因：可见音域只保证"比谱面实际音高宽一个八度"。窄音域的曲子就只显示一个八度，
而口琴能吹三个八度，于是可吹范围内的其它音高全在画面外。
改动：可见音域的最小跨度改为 **4 个八度**（47 个半音），按谱面实际音高居中展开。
超出可吹范围的音符照旧用浅灰色画出来 —— 现在它们一定在画面内，可以选中、拖动、删除。

【卷帘怎么用】


标尺点 / 拖       定位播放位置
琴键栏点          选中该音高的全部音符（拖动连选多个音高）
拖音符中部        移动。多选时整组一起动，左右改时间、上下改音高
拖音符任一端      改长度。左端改头、右端改尾，音高不变
空白处拖          框选多个音符
空白处单击        定位，并清空选择
双击空白          加音；按住继续拖可一次定好长度
右键 / Delete     删除（右键拖动可连擦）
Ctrl+A / Esc      全选 / 清空选择
方向键            微调：左右按吸附步长，上下按半音；按住 Shift 加速
Ctrl+Z / Ctrl+Y   撤销 / 重做（保留当前缩放位置）
滚轮              以光标为锚点缩放
Shift+滚轮        左右平移
中键拖动          左右平移
缩小 / 放大 / 全曲  工具栏按钮，右边显示当前缩放百分比
试听              和「停止」一样大的独立按钮，只放声音不发按键
帮助              展开 / 收起右侧操作说明

颜色：绿 = 可演奏。灰 = 超出音域。

【热键】
F6  开始 / 暂停 / 继续 / 取消倒计时
F5  后退 5 秒（从当前位置）
F7  前进 5 秒（从当前位置）

三个键都能在界面里改，也可以关掉。
播放中用热键跳转，可能让游戏侧口琴卡音。遇到卡音请按「停止」后重新播放。

【换轨会丢改动】
切换主旋律轨，或改合奏勾选，手动改动会被丢弃，日志里会写明。
想保住改动，先导出 MIDI。

【用法】
1. 打开 MIDI。绿点是推荐的主旋律轨。
2. 在卷帘或进度条上点/拖，调到要开始的位置。右侧显示定位处的音。
3. 点「▶ 播放」或按 F6。
4. 倒计时结束前切到游戏，装备口琴。

【注意】
- 游戏用窗口化，不要用全屏独占。
- 输入法切英文。人物原地站好再开始。
- 在线对局使用自动输入有封号风险，自行斟酌。
