口琴自动演奏器 v2.0.3

【本版】
修复：**试听时卷帘画面跟不上声音。**
现象：声音正常往前走，卷帘的画面却不跟着走，播放头很快跑出可视范围，
看起来就像"画面慢了一大截、声音跑远了"。

原因：卷帘的自动跟随只在 IsPlaying = true 时才生效，
而这个标志只在**演奏**分支里设置过，试听分支从来没设。
所以试听时视口一次都不滚动。

改法：试听开始设 IsPlaying = true，停止时按当前是否在演奏复位。

附带对齐：卷帘的时间轴比谱面末音长一点（末尾留了右键加音的余量），
而试听时钟走的是谱面时间。两者原来按同一个比例画，播放头会带约 2% 的偏差，
越到后面越明显。现在试听开始时按"谱面末音 ÷ 卷帘总长"换算一次，播放头与音符严格对齐。

修复：**输入法自检误报：中文键盘布局 + 英文模式被判为不通过。**
现象：键盘布局是中文、但按 Shift 切到英文时，自检打叉。
其实这个状态按键是直达游戏的，完全能用。

原因：旧实现只看键盘布局的 LANGID，是中文/日文就一律判不通过。
但"布局"和"输入法当前是中文还是英文"是两件事。

改法：布局是中日韩时，再去读输入法的真实状态：
- 输入法关着 → 英文直通，通过。
- 输入法开着但处于英文/半角模式（IME_CMODE_ALPHANUMERIC）→ 通过，并显示
  「简体中文布局已切英文模式，按键直达」，让你知道程序认出了这个状态。
- 输入法开着且是中文/假名状态 → 才判不通过，提示按 Shift 或 Ctrl+空格 切英文。
- 读不到状态 → 仍然提醒确认，但不假装知道结果。

开关状态用 WM_IME_CONTROL / IMC_GETOPENSTATUS 跨进程查询（最可靠，
不依赖本进程的输入法上下文），失败再退回 ImmGetContext。

验证：38 项判定用例全通过，覆盖简中/繁中/日文/韩文 ×
（开+英文模式 / 关 / 开+中文模式 / 读不到转换模式 / 读不到开关状态）以及英文布局。
本机实测：布局 0x0804（简体中文）+ 英文模式 → 通过，界面显示绿灯与新文案。
