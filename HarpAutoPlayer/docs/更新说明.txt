口琴自动演奏器 v1.1.0

【本版】
- 修复：部分 MIDI 载入后只能播前几秒。原因是自动推荐轨只看轨名和音符数、不看时长，
  可能选中开头几秒的前奏轨。现在推荐按时长覆盖率打分。
- 修复：换歌时没有重置播放位置，上一首停在哪，下一首可能从末尾开始。
- 新增 MIDI 卷帘：载入后即可点/拖定位；绿条=可演奏，灰条=超出音域。
- 新增 MIDI 编辑：加音、移动、改长度、删除。
- 新增撤销 / 重做（Ctrl+Z / Ctrl+Y），可一键「还原为自动」。
- 新增导出 MIDI：把编辑后的谱面写成标准 MIDI 文件。
- 定位处显示当前的音（音名 + 简谱 + 要按的键）。
- 新增快进 / 后退热键：默认 后退=F5、前进=F7，按一下走 5 秒，可改键。
- 体积优化：下载 37.9 → 15.5 MiB，解压后 90 → 21 MiB（功能不变）。

【卷帘怎么用】
双击空白          加一个音
拖动音符          移动。左右改时间，上下改音高
拖音符右缘        改长度
右键 / Delete     删除
点空白            定位播放位置
Ctrl+Z / Ctrl+Y   撤销 / 重做

勾选「吸附 0.1s」时按 0.1 秒对齐。关掉可以自由摆位。
改动只存在内存里。要留档请点「导出 MIDI…」。

【换轨会丢改动】
切换主旋律轨，或改合奏勾选，手动改动会被丢弃，日志里会写明。
想保住改动，先导出 MIDI。

【快进 / 后退的注意】
播放中用热键跳转，可能让游戏侧口琴卡音。遇到卡音请按「停止」后重新播放。

【用法】
1. 打开 MIDI。绿点是推荐的主旋律轨
2. 在卷帘或进度条上点/拖，调到要开始的位置。右侧显示定位处的音
3. 点「▶ 播放」或按 F6
4. 倒计时结束前切到游戏，装备口琴

【热键】
F6  开始 / 暂停 / 继续 / 取消倒计时
F5  后退 5 秒
F7  前进 5 秒
三个键都能在界面里改，也可以关掉。

【注意】
- 游戏用窗口化，不要用全屏独占
- 输入法切英文；人物原地站好再开始
- 在线对局使用自动输入有封号风险，自行斟酌
