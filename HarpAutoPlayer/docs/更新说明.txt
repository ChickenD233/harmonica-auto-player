口琴自动演奏器 v1.1.0

【本版】
- 修复：MIDI 谱面只加载一部分。根因是「自动提取主旋律」把换气休止（超过 0.12 秒）
  当成声部结束，把旋律切成多条声部；声部数上限又把中后段并进最后一条，
  于是得分最高的那条常常只覆盖歌曲的一段，前面整段丢失。
  现在选出声部后，会把与它时间上不重叠、同样像旋律的其他声部一并取回。
  实测：96 音分句旋律 + 密集伴奏，修复前只剩 56 音（从 50.0s 才开始），
  修复后 96 音完整覆盖 0.0-114.7s。
- 新增卷帘缩放：滚轮缩放，Shift+滚轮平移，中键拖动平移。工具栏有缩小 / 放大 / 全曲。
  整首歌挤进几百像素时一个音只有 1-2 像素，不缩放没法编辑。
- 修复卷帘命中：音域宽时每行不足 2 像素，原来先按音高行过滤会点不中，改为就近命中。
- 修复点击卡顿：选中音符不再重算整条提取管线。
- 界面重排：日志列表去掉，改为底部单行消息；完整历史仍写入 play.log。
  「输入兼容」与「播放前自检」移到左栏声道列表下方，右栏不再被挤出窗口。
  卷帘改为弹性高度，窗口变小时优先压缩它。
- 修复：部分 MIDI 载入后只能播前几秒（自动推荐轨不看时长，可能选中开头几秒的前奏轨）。
- 修复：换歌时没有重置播放位置，上一首停在哪，下一首可能从末尾开始。
- 新增 MIDI 编辑：加音、移动、改长度、删除，撤销 / 重做，导出 MIDI。
- 新增快进 / 后退热键：默认 后退=F5、前进=F7，按一下走 5 秒，可改键。
- 体积优化：下载 37.9 → 15.5 MiB，解压后 90 → 21 MiB（功能不变）。

【卷帘怎么用】
双击空白          加一个音
拖动音符          移动。左右改时间，上下改音高
拖音符右缘        改长度
右键 / Delete     删除
点空白            定位播放位置
Ctrl+Z / Ctrl+Y   撤销 / 重做

滚轮              缩放
Shift+滚轮        左右平移
中键拖动          左右平移
缩小 / 放大 / 全曲  工具栏按钮

勾选「吸附 0.1s」时按 0.1 秒对齐。关掉可以自由摆位。
改动只存在内存里。要留档请点「导出 MIDI…」。

【换轨会丢改动】
切换主旋律轨，或改合奏勾选，手动改动会被丢弃，日志里会写明。
想保住改动，先导出 MIDI。

【快进 / 后退的注意】
播放中用热键跳转，可能让游戏侧口琴卡音。遇到卡音请按「停止」后重新播放。

【用法】
1. 打开 MIDI。绿点是推荐的主旋律轨
2. 在卷帘或进度条上点/拖，调到要开始的位置。右侧显示定位处的音
3. 点「▶ 播放」或按 F6
4. 倒计时结束前切到游戏，装备口琴

【热键】
F6  开始 / 暂停 / 继续 / 取消倒计时
F5  后退 5 秒
F7  前进 5 秒
三个键都能在界面里改，也可以关掉。

【注意】
- 游戏用窗口化，不要用全屏独占
- 输入法切英文；人物原地站好再开始
- 在线对局使用自动输入有封号风险，自行斟酌
