口琴自动演奏器 v1.0.7 更新说明
================================

【本版重点：修复游戏内「缺音 / 漏音」】

问题原因
--------
游戏按键是**按帧读取**的（60fps 一帧约 16.7ms，30fps 一帧约 33ms）。
旧版把「松开上一个音 + 鼠标八度键 + 鼠标中键(升半音) + 本音按下」
这四类事件全挤在约 20ms 内发出，音键永远排在最后一位。
当这一簇被游戏折进同一帧时，游戏只认到修饰键变化，
**排在最末尾的音键就被吃掉了 —— 这就是漏音的来源**。

用本程序自带示例 MIDI 实测旧版：
  · 示例2「升降与高音演示」：88.9% 的音，修饰键只提前 8ms，其中 1 个与音键同一时刻(0ms)；
  · 示例1 / 示例3：87% / 96% 的音，「前音松开 + 后音按下」落在同一帧内。

不是键盘能同时按几个键不够（最多只同时按鼠标两个键 + 一个音键），
而是一帧内塞进的输入事件太多，音键正好是最后那个。

修复内容
--------
1. 修饰键改为**状态机**：只发真实的状态变化，先松开不该按的、再按下该按的，
   顺序固定；不再把四类事件挤成一簇。
2. 所有最小间隔改用**物理时间**，并按帧给足余量：
     修饰键比音键提前 ≥ 1 帧（默认 40ms）
     音键最短按住 ≥ 1 帧（默认 45ms）
     同一根音键两次按下间隔 ≥ 1 帧（默认 45ms，旧版只有 12ms）
     前音松开 → 后音按下留出跨帧间隙
3. 最小间隔**不再随播放速度被压缩**。旧版调快速度会把 12ms 压到 2.4ms，必然粘连。
4. 修正提前量被速度放大的问题（旧版 5 倍速下提前量膨胀到 125ms，画面与声音错位）。
5. 换歌 / 拖动进度条后强制释放并复位修饰键状态，避免「程序以为中键还按着」
   导致后面整段音高不对。
6. 极快段落（同键连击极密）改为按「本音可用时长」自适应收敛，
   避免旧版把音一直往后推、时值归零导致连续丢音。

新增功能
--------
◆ 「输入兼容」档位（选项区，默认「标准」）
    稳健：给 30fps / 掉帧 / 机器卡顿时留更多余量（若仍漏音请选它）
    标准：60fps 推荐，绝大多数机器适用
    极限：帧率很高、需要跟很快的歌时用（余量最小）
  档位会被记住，下次启动自动恢复。

◆ 播放时序诊断
  每次播放结束或停止时，日志区会输出一行诊断，例如：
    「时序诊断：音符 128 个；修饰键提前量<16.7ms 的 0 个（同刻 0 个）；
      同键重触发<45ms 的 0 个；按住<16.7ms 的 0 个；最小修饰键提前量 40.0ms」
  若这几项都是 0，说明输入时序已不是瓶颈；若不为 0，请把「输入兼容」改成「稳健」。

实测改善（自带示例 MIDI，60fps）
--------------------------------
    修饰键提前量 ≥ 2 帧 的音：  65.6%  →  96.9%
    提前量不足一帧(<16.7ms)：   21.9%  →  0%
    与音键完全同刻(0ms)的修饰键： 1 个   →  0 个
    最小修饰键提前量：           0ms    →  16.7ms

使用建议（若仍有漏音）
----------------------
1. 先把「输入兼容」改成「稳健」再试；
2. 若是密集同键重复音，把速度降回 100%（这类音受物理极限限制，
   只能二选一：要么漏音、要么轻微粘连，本版优先保证「能听见」）；
3. 若诊断显示时序已全部达标却仍漏音，则问题不在时序，请检查：
   输入法切英文、以管理员身份运行、游戏用无边框窗口化、
   播放前点一下游戏画面让游戏拿到焦点。

【重要】为什么「边走边弹」一定会漏音（无法修复）
------------------------------------------------------------
结论先说：**本软件只能保证「原地不动演奏」不漏音。**
按住移动键边走边弹时的漏音，来自键盘硬件与游戏本身，
**任何软件都无法修复**，请不要把它当成程序缺陷反馈。

原因：
  · 键盘内部是「行 × 列」扫描矩阵，芯片逐行扫描来定位按键。
    同时按下的键若占满一个矩形的三个角（跨 2 行 2 列），
    第四个角在电学上「看起来也导通」，芯片无法分辨，
    于是**直接丢弃后按下的那个键** —— 这就是「幽灵按键」。
  · 便宜的 6 键无冲（6KRO）键盘尤其明显；
    只有**全键无冲（NKRO）键盘**才彻底没有这个问题。
  · 所以按住 W（或 W+A、或 Shift 跑动）时，
    口琴那排 `Z X C V B N M ,` 里会有一部分键被键盘本身吞掉。
    **站着不动时没有 W，自然就不漏** —— 这正是区分
    「软件时序问题」与「键盘矩阵冲突」的关键。

本版已经修掉的部分：
  软件这一侧的时序问题（修饰键只提前 8ms、同键重触发只有 12ms，
  都短于一帧）是本版修掉的真 bug。所以现在**原地演奏不会再漏音**。
  余下的走位漏音在硬件层，软件无能为力。

想要边走边弹，只能从硬件/键位下手：
  1. 换一把全键无冲（NKRO）机械键盘 —— 最彻底，冲突从根上消失；
  2. 改口琴键位：实测出哪几个音键与 W 冲突后，在游戏里改到不冲突的一组；
  3. 用鼠标侧键映射音键（鼠标走独立通道，不参与键盘矩阵）；
  4. 权宜之计：需要弹的乐句上先松开移动键。
