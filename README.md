# 口琴自动演奏器（《三角洲行动》）

导入标准 MIDI 文件并选择主旋律后，自动模拟**键盘 + 鼠标**，把旋律在游戏《三角洲行动》的口琴上「吹」出来。

- 支持系统：Windows 10 / 11（64 位）
- 成品为**单文件 exe**，无需安装 .NET 等任何运行库
- 语言：中文界面

> ⚠️ **重要声明**：本工具通过模拟按键/鼠标代替人工演奏。在**在线对局**中使用自动输入违反游戏用户协议与反作弊规则，存在**账号封禁风险**。请仅在练习、自定义房间、单机等安全场景使用；由此产生的一切后果由使用者自行承担。

---

## 功能特性

- 打开任意标准 MIDI（`.mid` / `.midi` / `.kar` / `.rmi`），左侧按（轨道, 声道）列出，**单击一行**即作为主旋律；
- **速度 / 移调（±10 半音）/ 倒计时**均可调：播放中实时生效；「一键移调」自动把旋律整体移到口琴音域内；
- 「**同刻多音取最高（还原主旋律）**」（默认开）：口琴一次只能吹一个音，同一瞬间多个音同时响时只吹**最高**的那个音（主旋律通常在最高声部，最贴近原曲）；
- 「**去除开头空拍**」（默认开）：很多 MIDI 开头有几小节休止/空白，勾选后自动把起始静音剪掉，让旋律从第 0 秒直接开始，不必先干等几秒；
- 「**呼吸休止**」：连续吹奏过久自动插入极短停顿，避免长连吹导致游戏判定粘连；
- **全局热键**：默认 `F5` = 开始/继续，`F6` = 暂停/继续，游戏中直接生效，可改为 F1–F12 或关闭；
- **记住设置**：速度/移调/倒计时/热键/各选项自动记忆，下次启动恢复；
- **托盘后台**：点窗口 × 隐藏到系统托盘，托盘菜单可显示窗口 / 开始 / 暂停 / 停止 / 退出；
- **本地日志**：`%LOCALAPPDATA%\HarpAutoPlayer\play.log`（自动轮转，便于排查问题）；
- 附带「本地钢琴测试台」网页与 4 首示例 MIDI，**无需进游戏**即可先验证按键输出。

## 快速开始（下载成品）

1. 打开本仓库右侧 **Releases**，下载最新版 `HarpAutoPlayer-win-x64.zip`（当前 **v1.0.2**）；
2. 解压后里面只有一个 `HarpAutoPlayer.exe`，双击即可运行；
3. 首次运行若弹出 SmartScreen“未知发布者”：点「更多信息」→「仍要运行」；
4. 个别杀毒软件可能误报“模拟按键”，请加入信任/白名单，并只从你信任的来源获取本软件。

## 使用方法

1. 点「打开 MIDI」，选择 `.mid` / `.midi` / `.kar` / `.rmi` 文件（可先用 `示例MIDI/` 里的文件试手）；
2. 在左侧轨道/声道列表中**单击一行**作为主旋律（有和声/伴奏时，选旋律所在轨）；
3. 按需设置 **速度 / 移调 / 倒计时**，并按需勾选处理选项（默认：「同刻多音取最高」「去除开头空拍」为开；「人声旋律提取」「呼吸休止」为关）；
4. 点「▶ 播放」（或按开始热键，默认 `F5`），在倒计时内切到游戏、装备口琴即可；
5. 播放中可拖进度条跳转、实时变速/移调；
6. 结束点「停止」或关闭窗口——程序会把焦点还给正在播放的游戏窗口并补发一次“全部松开”，确保口琴不会一直响。

## 使用注意事项（开始前请通读）

1. 游戏请使用**窗口化或无边框窗口化**（全屏独占模式收不到模拟按键）；
2. 点「播放」开始演奏后，请**点击一下游戏画面**，让游戏获得焦点并处于前台；
3. 暂停键默认是 **F6**：发现鼠标/键盘不受控制、需要紧急停止时，按 F6 即可暂停/继续；
4. MIDI 文件尽量选择**分音轨、无和弦**的版本（只保留主旋律一个声部最稳定）；若 MIDI 含和弦/多音，请保持「同刻多音取最高」勾选（程序会自动取最高音）；
5. 输入法请切换成**英文输入法**（中文输入法会截走按键导致漏音）；
6. 游戏内请**原地不动**再使用本软件：移动、打开背包、与场景交互等会造成键位冲突、导致漏音；
7. 请**以管理员身份运行**本软件（当游戏以管理员身份运行时尤其重要，否则模拟按键可能发不进游戏）。

## 可演奏音域（与三角洲口琴一致）

- 键盘 `Z X C V B N M ，`（逗号）= 中音 do re mi fa sol la si + 高音 do；
- 按住鼠标**左键** = 整排降到低八度；按住**右键** = 整排升到高八度；
- 右键 + 逗号 = 高高音 do；右键 + **中键** + 逗号 = 高高音 #do；每个键 + 中键 = 升半音；
- 可演奏范围：**低音 do ～ 高高音 #do**，超出范围的音自动**空拍**；
- 基准八度自动选择（取旋律音符最集中的八度）。

## 全局热键

- 默认：**F5** = 开始/继续，**F6** = 暂停/继续；界面里可改成 F1–F12 或“无”；
- 使用系统低层键盘钩子，无需额外授权；退出软件后热键自动注销；
- 按键以**扫描码**方式发送（对大多数游戏兼容性最好、受输入法干扰最小）。

## 常见问题

**游戏里没反应，但在记事本/Word 里能打字？**
多为焦点或权限问题，依次检查：
1. 播放前先**点一下游戏画面**，确保游戏在前台（软件日志会提示当前前台窗口）；
2. 游戏显示模式改为**无边框窗口化**（勿用全屏独占）；
3. 游戏以管理员运行时，本程序也请**以管理员身份运行**；
4. 游戏内切成**英文键盘**（关闭中文输入法）。

**点窗口 × 后程序还在？**
是的，点 × 是隐藏到**系统托盘**（右下角“上箭头”里）；托盘菜单选「退出」才会真正关闭。

**出错 / 卡住怎么办？**
看界面右下日志区，或文件 `%LOCALAPPDATA%\HarpAutoPlayer\play.log`（可发给开发者排查）。

**设置会记住吗？**
会。配置文件保存在 `%LOCALAPPDATA%\HarpAutoPlayer\settings.json`。

## 本地钢琴测试台（自测，无需进游戏）

打开仓库里的 `口琴钢琴测试台.html`：单文件网页，按键/鼠标规则与三角洲口琴完全一致，带发声与音名显示，范围 低音 do ～ 高高音 #do。
用它验证自动演奏输出：打开页面并点击获得焦点 → 保持光标在页面内 → 运行本软件播放 → 页面会逐个亮音。左键/右键/中键通过鼠标事件识别，因此**请保持光标在页面内**。

## 技术说明

- UI：Avalonia（.NET 8）；MIDI 解析：DryWetMidi（支持 UTF-8 轨道名）；
- 时间轴按“音乐时间”积分：速度可实时改、进度可拖拽跳转、移调可实时重映射；
- 输入：Windows SendInput（扫描码模式）；全局热键：WH_KEYBOARD_LL；
- 主旋律按单音处理，重叠自动切音；同键连音强制 ≥12ms 重触发间隔。
