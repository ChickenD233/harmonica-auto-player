# 口琴自动演奏器（《三角洲行动》）

导入 MIDI，选一条主旋律，程序自动模拟**键盘 + 鼠标**，在游戏口琴上吹出来。

- Windows 10 / 11（64 位），单文件 exe，**不需要装 .NET**
- 中文界面

> ⚠️ 在**在线对局**中使用自动输入违反游戏协议，存在**封号风险**。请只在练习、自定义房间、单机场景使用，后果自负。

## 下载

1. 打开右侧 **Releases**，下载 `HarpAutoPlayer-win-x64.zip`（当前 **v1.0.10**）
2. 解压后双击 `HarpAutoPlayer.exe`，会弹 UAC，选「是」
3. 若弹 SmartScreen「未知发布者」：更多信息 → 仍要运行
4. 杀毒软件可能误报「模拟按键」，请加白名单

## 使用

1. 点「打开 MIDI 文件…」，选 `.mid` / `.midi` / `.kar` / `.rmi`（可先用 `示例MIDI/` 试手）
2. 左侧点一行作为主旋律。绿点是自动推荐的，打击乐轨不可选
3. 按需调速度 / 移调 / 倒计时
4. 点「▶ 播放」或按 **F6**，在倒计时内切到游戏并装备口琴

播放中可拖进度条跳转、实时变速移调。暂停时可直接打开另一首换歌。结束点「停止」或关窗口，程序会把焦点还给游戏并补发一次全部松开。

## 注意

1. 游戏用**窗口化或无边框窗口化**，全屏独占收不到模拟按键
2. 开始后**点一下游戏画面**，让游戏处于前台
3. 输入法切**英文**，中文输入法会截走按键
4. **游戏内原地不动**：按住 `W`/`A`/`S`/`D` 时键盘矩阵会吞掉部分音键（幽灵按键，6KRO 键盘尤其明显）。这是**键盘硬件限制，软件无法修复**，只能换全键无冲（NKRO）键盘
5. 程序已强制以管理员启动。游戏以管理员运行时本程序也必须是，否则按键被 Windows 拦截
6. 鼠标/键盘失控时，**狂按 F6** 可安全停住

## 可演奏音域

- `Z X C V B N M ,` = 中音 do re mi fa sol la si + 高音 do
- 按住鼠标**左键** = 降八度；按住**右键** = 升八度
- 右键 + 逗号 = 高高音 do；右键 + 中键 + 逗号 = 高高音 #do；任意键 + 中键 = 升半音
- 范围 **低音 do ～ 高高音 #do**，超出的音自动空拍

## 键位与选项

- **控制键**：默认 **F6**，一个键四用——空闲=开始，播放=暂停，暂停=继续，倒计时=取消。可改 F1–F12 或关闭。用系统低层键盘钩子，游戏中直接生效
- **自动提取主旋律**（默认开）：先分声部再挑旋律轨。旧做法「同刻取最高音」在钢琴/吉他改编曲里会取到伴奏琶音，系统性取错
- **去除开头空拍**（默认开）：剪掉开头的休止，旋律从第 0 秒开始
- **输入兼容**（稳健/标准/极限）：游戏按帧采样按键，修饰键与音键间隔小于一帧就漏音。掉帧的机器选「稳健」
- **呼吸休止**：长连吹时插入极短停顿
- **人声旋律提取**：伴奏与主唱在同一轨时用
- **导出按键表**：罗技 G HUB 脚本（.lua）或通用 CSV，内容与实际演奏一致
- 设置自动记忆到 `%LOCALAPPDATA%\HarpAutoPlayer\settings.json`，日志在 `play.log`

## 常见问题

**游戏里没反应，但在记事本能打字？**
按顺序查：① 先点一下游戏画面 ② 游戏改无边框窗口化 ③ 游戏与本程序都用管理员 ④ 输入法切英文。

**站着不动不漏，一走位就漏音？**
键盘硬件的幽灵按键问题，不是软件。见「注意」第 4 条。

**偶尔缺音？**
看日志区播放结束时的「时序诊断」：修饰键提前量不足，把「输入兼容」改成「稳健」；同键重触发偏多，把速度降回 100%。

**点窗口 × 会怎样？**
彻底退出：停止播放、松开所有按键、注销热键。只想暂时离开就最小化，用托盘菜单控制。

## 自测（不进游戏）

打开 `口琴钢琴测试台.html`。按键规则与游戏口琴一致，带发声与音名显示。运行本软件播放，页面会逐个亮音——**保持光标在页面内**。

## 技术说明

- UI：Avalonia（.NET 8）；MIDI 解析：DryWetMidi
- 输入：Windows SendInput（扫描码）；全局热键：WH_KEYBOARD_LL
- 时序按**物理帧**给余量：修饰键提前 ≥1 帧、按住 ≥1 帧、同键重触发 ≥1 帧。最小间隔用物理毫秒，不随播放速度压缩
- 时序带状态机：只发真实修饰键差分，换谱或拖进度条后强制释放并复位
