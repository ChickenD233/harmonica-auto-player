# 口琴自动演奏器（《三角洲行动》）

导入 MIDI。程序模拟键盘和鼠标，在游戏口琴上吹出旋律。
内置 MIDI 编辑器，可以先改谱，再演奏。

- 系统：Windows 10 / 11（64 位）
- 单文件 exe。不需要安装 .NET
- 界面语言：中文

> ⚠️ 在线对局使用自动输入违反游戏协议，有封号风险。请只在练习、自定义房间、单机场景使用。后果由使用者承担。

## 下载

1. 打开右侧 **Releases**。
2. 下载 `HarpAutoPlayer-win-x64.zip`。
3. 解压。双击 `HarpAutoPlayer.exe`。
4. 系统弹出 UAC，选「是」。
5. 如果弹出 SmartScreen「未知发布者」，选「更多信息」，再选「仍要运行」。
6. 杀毒软件可能误报「模拟按键」。请把它加入白名单。

## 使用

1. 点「打开 MIDI 文件…」。支持 `.mid`、`.midi`、`.kar`、`.rmi`。
2. 在左侧点一行，作为主旋律。绿点是程序推荐的行。打击乐轨不能选。
3. 需要改谱时，在卷帘上直接改。做法见下。
4. 调速度、移调、倒计时。
5. 点「▶ 播放」，或按 **F6**。
6. 在倒计时结束前切到游戏。装备口琴。

播放中，你可以拖卷帘或进度条跳转。也可以实时改速度和移调。暂停时可以直接打开另一首换歌。

## 卷帘编辑

卷帘画出整首旋律。上方是时间标尺，按文件的拍号与速度画小节线。左侧是琴键栏。

| 操作 | 作用 |
|---|---|
| 标尺点 / 拖 | 定位播放位置 |
| 点左侧琴键 | 选中该音高的全部音符。按住拖动可连选多个音高 |
| 拖音符中部 | 移动。多选时整组一起动。左右改时间，上下改音高 |
| 拖音符任一端 | 改长度。左端改头，右端改尾。音高不变 |
| 空白处拖 | 框选多个音符 |
| 空白处单击 | 定位，并清空选择 |
| 双击空白 | 加一个音。按住继续拖可一次定好长度 |
| 右键 | 删音。按住拖动可连续擦除 |
| Delete | 删除选中的音 |
| Ctrl+A / Esc | 全选 / 清空选择 |
| 方向键 | 微调。左右按吸附步长，上下按半音。按住 Shift 加速 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做。保留当前缩放位置 |
| 滚轮 | 以光标为锚点缩放 |
| Shift+滚轮 | 左右平移 |
| 中键拖动 | 左右平移 |
| 缩小 / 放大 / 全曲 | 工具栏按钮。右边显示当前缩放百分比 |
| 帮助 | 展开 / 收起右侧的操作说明 |

**颜色。** 绿 = 可演奏。灰 = 超出音域。

**吸附。** 勾选「吸附 0.1s」后，拖动与加音按 0.1 秒对齐。吸附的是音符的头或尾，不是光标。

**改动只存在内存里。** 要留档，点「导出 MIDI…」。程序写出一个标准 MIDI 文件。

**换轨会丢改动。** 切换主旋律轨，或改合奏勾选，程序会丢弃手动改动。日志会写明。想保住改动，先导出 MIDI。

## 试听

点「试听」按钮，用 Windows 自带的 MIDI 合成器播放当前谱面。再点一下停止。

- 它和演奏完全分开：不发送按键，不走倒计时，不会最小化窗口。
- 播放中随时可以拖进度条或卷帘定位。松手就从新位置接着放。
- 不需要安装任何音频软件。设备不可用时按钮会自动变灰，日志里写明原因。

## 选项

- **合奏**。在左侧勾选多个声部一起吹。编号 1 最优先。口琴一次只能吹一个音，冲突时先吹编号小的。
- **去除开头空拍**。默认开。剪掉开头的休止，让旋律从第 0 秒开始。卷帘左下角会标出剪掉多少秒。
- **输入兼容**。三档：稳健、标准、极限。游戏按帧读按键。修饰键与音键的间隔小于一帧就会漏音。掉帧的机器选「稳健」。
- **播放后自动最小化窗口**。默认开。
- **导出按键表**。导出罗技 G HUB 脚本（.lua），或通用 CSV。内容与实际演奏一致。

设置自动记忆。位置是 `%LOCALAPPDATA%\HarpAutoPlayer\settings.json`。日志在同一目录，文件名是 `play.log`。

## 热键

程序用系统低层键盘钩子。热键在游戏中直接生效。

| 键 | 动作 |
|---|---|
| **F6** | 空闲 = 开始。播放中 = 暂停。暂停中 = 继续。倒计时中 = 取消 |
| **F5** | 后退 5 秒 |
| **F7** | 前进 5 秒 |

三个键都能改，也能关掉。在界面的「控制热键」「后退热键」「前进热键」里改。

**注意**：播放中跳转可能让游戏侧口琴卡音。遇到卡音，按「停止」，再重新播放。最稳的用法是播放前用卷帘或进度条定位。

## 注意

1. 游戏用**窗口化**或**无边框窗口化**。全屏独占收不到模拟按键。
2. 播放开始前，点一下游戏画面。游戏必须在前台。
3. 输入法切到**英文**。中文输入法会截走按键。
4. 游戏内**原地不动**。按住 `W`、`A`、`S`、`D` 时，键盘矩阵会吞掉部分音键。这是键盘硬件限制，软件无法修复。只有全键无冲（NKRO）键盘可以避免。
5. 程序强制以管理员启动。游戏以管理员运行时，本程序也必须是管理员。否则 Windows 拦截按键。
6. 鼠标或键盘失控时，狂按 **F6**。

## 可演奏音域

- `Z X C V B N M ,` 对应中音 do re mi fa sol la si 和高音 do。
- 按住鼠标**左键**，整排降一个八度。按住**右键**，整排升一个八度。
- 右键加逗号，得到高高音 do。右键加中键加逗号，得到高高音 #do。任意键加中键，升半音。
- 可演奏范围是低音 do 到高高音 #do。超出范围的音自动空拍，在卷帘上显示为灰色。

## 自测（不进游戏）

打开 `口琴钢琴测试台.html`。页面规则与游戏口琴一致，有发声和音名显示。

运行本软件播放。页面会逐个亮音。**保持光标在页面内**。

## 常见问题

**游戏里没反应，但在记事本能打字？**

按顺序检查四项。

1. 先点一下游戏画面。
2. 游戏改成无边框窗口化。
3. 游戏和本程序都用管理员。
4. 输入法切英文。

**站着不动不漏音，一走位就漏音？**

这是键盘硬件的幽灵按键问题，不是软件问题。见上面「注意」第 4 条。

**偶尔缺音？**

看日志区里播放结束时的「时序诊断」。

- 修饰键提前量不足：把「输入兼容」改成「稳健」。
- 同键重触发偏多：把速度降回 100%。

**点窗口的 × 会怎样？**

彻底退出。程序停止播放，松开所有按键，注销热键。只想暂时离开游戏画面，就最小化窗口。托盘菜单可以控制开始、暂停、停止和退出。

## 技术说明

- 界面：Avalonia（.NET 8）。MIDI 解析：DryWetMidi。
- 输入：Windows SendInput，扫描码模式。全局热键：WH_KEYBOARD_LL。
- 试听：Windows 自带的 winmm MIDI 输出。没有第三方音频库。
- 时序按物理帧给余量。修饰键提前至少 1 帧。音键按住至少 1 帧。同键重触发至少 1 帧。最小间隔用物理毫秒，不随播放速度压缩。
- 卷帘坐标换算只有一套。渲染与命中共用，两个方向对称。
