# 口琴自动演奏器（《三角洲行动》）

导入标准 MIDI 文件并选择主旋律后，自动模拟**键盘 + 鼠标**，把旋律在游戏《三角洲行动》的口琴上「吹」出来。

- 支持系统：Windows 10 / 11（64 位）
- 成品为**单文件 exe**，无需安装 .NET 等任何运行库
- 语言：中文界面

> ⚠️ **重要声明**：本工具通过模拟按键/鼠标代替人工演奏。在**在线对局**中使用自动输入违反游戏用户协议与反作弊规则，存在**账号封禁风险**。请仅在练习、自定义房间、单机等安全场景使用；由此产生的一切后果由使用者自行承担。

## 功能特性

- 打开任意标准 MIDI（`.mid` / `.midi` / `.kar` / `.rmi`），左侧按（轨道, 声道）列出，**单击一行**即作为主旋律；
- **载入容错**：文件里损坏的调号/控制事件等“脏数据”（如非法的 scale=255）会被自动就近纠正，不会整首打不开；
- **自动推荐主旋律轨**：载入后自动选中并 ★ 标出最像旋律的那条轨（非打击乐、音域贴合）；打击乐等不适合的轨道整行置灰禁用；列表同时显示每条声部的**时长**；
- **首次使用引导**：第一次启动弹出「快速上手」三步说明（之后不再出现），老用户升级不会重复打扰；
- **速度 / 移调（±10 半音）/ 倒计时**均可调：播放中实时生效；「一键移调」自动把旋律整体移到口琴音域内；
- 「**同刻多音取最高（还原主旋律）**」（默认开）：口琴一次只能吹一个音，同一瞬间多个音同时响时只吹**最高**的那个音（主旋律通常在最高声部，最贴近原曲）；
- 「**去除开头空拍**」（默认开）：很多 MIDI 开头有几小节休止/空白，勾选后自动把起始静音剪掉，让旋律从第 0 秒直接开始，不必先干等几秒；
- 「**输入兼容档位**」（稳健 / 标准 / 极限）：游戏按键是**按帧采样**的，若"修饰键（鼠标左右中键）"与"音键"的间隔小于一帧，这一簇事件会被游戏折进同一帧、音键被吃掉 —— 这就是漏音的主因。程序已按物理时间给足余量（修饰键提前一帧以上、同键重触发与按住时长都跨帧），并提供三档让低帧率/卡顿机器选「稳健」；播放结束/停止时日志会输出**时序诊断**（修饰键提前量不足一帧的音有几个），可自证是否还有漏音；
- 「**呼吸休止**」：连续吹奏过久自动插入极短停顿，避免长连吹导致游戏判定粘连；
- **统一控制键**：整个控制只有一个键，默认 **F6** —— 空闲按它=开始、播放中按它=暂停、暂停中按它=继续、倒计时中按它=取消，游戏中直接生效；可改为 F1–F12 或关闭；
- **播放后自动最小化（可关）**：默认开始播放后窗口自动缩到任务栏；想放在副屏看播放进度，就取消勾选「播放后自动最小化窗口」，窗口会保持原样（此时记得点一下游戏画面让游戏拿到焦点）；
- **记住设置**：速度/移调/倒计时/控制键/各选项自动记忆，下次启动恢复；
- **托盘后台**：窗口最小化后程序仍在后台运行，托盘菜单可显示窗口 / 开始 / 暂停 / 停止 / 退出；点窗口 **×** 则会彻底退出（自动松开所有按键并注销热键）；
- **本地日志**：`%LOCALAPPDATA%\HarpAutoPlayer\play.log`（自动轮转，便于排查问题）；
- 附带「本地钢琴测试台」网页与 4 首示例 MIDI，**无需进游戏**即可先验证按键输出。

## 快速开始（下载成品）

1. 打开本仓库右侧 **Releases**，下载最新版 `HarpAutoPlayer-win-x64.zip`（当前 **v1.0.7**）；
2. 解压后有 `HarpAutoPlayer.exe` 与「更新说明.txt」（本版更新内容），双击 exe 即可运行；
3. 首次运行若弹出 SmartScreen“未知发布者”：点「更多信息」→「仍要运行」；
4. 个别杀毒软件可能误报“模拟按键”，请加入信任/白名单，并只从你信任的来源获取本软件。

## 使用方法

1. 点「打开 MIDI」，选择 `.mid` / `.midi` / `.kar` / `.rmi` 文件（可先用 `示例MIDI/` 里的文件试手）；
2. 在左侧轨道列表中**选一条主旋律**（载入后程序会先自动选中推荐轨，可再点其它行；打击乐轨不可选）；
3. 按需设置 **速度 / 移调 / 倒计时**，并按需勾选处理选项（默认：「同刻多音取最高」「去除开头空拍」为开；「人声旋律提取」「呼吸休止」为关）；
4. 点「▶ 播放」或直接按 **F6** —— 同一个键再按=暂停、再按=继续；倒计时会以大字显示，切到游戏、装备口琴即可；
5. 播放中可拖进度条跳转、实时变速/移调；**暂停时可直接打开另一首 MIDI 换歌**（会自动先停掉当前曲目）；
6. 结束点「停止」或关闭窗口——程序会把焦点还给正在播放的游戏窗口并补发一次“全部松开”，确保口琴不会一直响。

## 使用注意事项（开始前请通读）

1. 游戏请使用**窗口化或无边框窗口化**（全屏独占模式收不到模拟按键）；
2. 点「播放」开始演奏后，请**点击一下游戏画面**，让游戏获得焦点并处于前台；
3. 整个控制就一个键：默认 **F6** —— 空闲按=开始 / 播放中按=暂停 / 暂停中按=继续 / 倒计时中按=取消；发现鼠标/键盘不受控制时，狂按 F6 即可安全停住；
4. MIDI 文件尽量选择**分音轨、无和弦**的版本（只保留主旋律一个声部最稳定）；若 MIDI 含和弦/多音，请保持「同刻多音取最高」勾选（程序会自动取最高音）；
5. 输入法请切换成**英文输入法**（中文输入法会截走按键导致漏音）；
6. 游戏内请**原地不动**再使用本软件：移动、打开背包、与场景交互等会造成键位冲突、导致漏音；
7. 请**以管理员身份运行**本软件（当游戏以管理员身份运行时尤其重要，否则模拟按键可能发不进游戏）。

## 可演奏音域（与三角洲口琴一致）

- 键盘 `Z X C V B N M ，`（逗号）= 中音 do re mi fa sol la si + 高音 do；
- 按住鼠标**左键** = 整排降到低八度；按住**右键** = 整排升到高八度；
- 右键 + 逗号 = 高高音 do；右键 + **中键** + 逗号 = 高高音 #do；每个键 + 中键 = 升半音；
- 可演奏范围：**低音 do ～ 高高音 #do**，超出范围的音自动**空拍**；
- 基准八度自动选择（取旋律音符最集中的八度）。

## 控制键（全局热键）

- 整个控制就一个键，默认 **F6**：空闲按 = 开始；倒计时中按 = 取消；播放中按 = 暂停；暂停中按 = 继续。界面「控制热键」里可改成 F1–F12 或“无”；
- 使用系统低层键盘钩子，游戏中直接生效，无需额外授权；退出软件后热键自动注销；
- 按键以**扫描码**方式发送（对大多数游戏兼容性最好、受输入法干扰最小）。

## 常见问题

**游戏里没反应，但在记事本/Word 里能打字？**
多为焦点或权限问题，依次检查：
1. 播放前先**点一下游戏画面**，确保游戏在前台（软件日志会提示当前前台窗口）；
2. 游戏显示模式改为**无边框窗口化**（勿用全屏独占）；
3. 游戏以管理员运行时，本程序也请**以管理员身份运行**；
4. 游戏内切成**英文键盘**（关闭中文输入法）。

**点窗口 × 会怎样？**
点 × = **彻底退出**：播放停止、所有按键自动松开、全局热键注销。播放中若只想暂时离开游戏画面，把窗口最小化即可，用系统托盘菜单（右下角“上箭头”内）控制开始/暂停/停止/退出。

**游戏里偶尔缺音/漏音怎么办？**
先看界面日志区（或 `%LOCALAPPDATA%\HarpAutoPlayer\play.log`）每次播放结束时那行「时序诊断」：
1. 若「修饰键提前量<16.7ms」的数字不为 0，说明输入时序余量不足 —— 把「**输入兼容**」改成「**稳健**」再试；
2. 若是快速同键重复音（同键重触发<45ms）偏多，属物理极限：把**速度降回 100%**，或换分音轨的 MIDI；
3. 「时序诊断」全 0 但仍漏音，则问题不在输入时序，请按下面「游戏里没反应」的焦点/权限/输入法逐项排查（尤其：输入法切英文、以管理员运行、无边框窗口化、游戏内原地不动）。

**出错 / 卡住怎么办？**
看界面右下日志区，或文件 `%LOCALAPPDATA%\HarpAutoPlayer\play.log`（可发给开发者排查）。

**设置会记住吗？**
会。配置文件保存在 `%LOCALAPPDATA%\HarpAutoPlayer\settings.json`。

## 技术说明

- UI：Avalonia（.NET 8）；MIDI 解析：DryWetMidi（支持 UTF-8 轨道名）；
- 时间轴按“音乐时间”积分：速度可实时改、进度可拖拽跳转、移调可实时重映射；
- 输入：Windows SendInput（扫描码模式）；全局热键：WH_KEYBOARD_LL；
- 主旋律按单音处理，重叠自动切音；
- **输入时序按物理帧给余量**：修饰键比音键提前 ≥1 帧、音键按住 ≥1 帧、同键重触发 ≥1 帧；所有最小间隔都用物理毫秒，**不再随播放速度被压缩**（旧版 5x 速度下 12ms 重触发间隔会被压到 2.4ms，必然粘连）；
- 输入时序带**状态机**：只发真实的修饰键差分，换谱/拖进度条后强制释放并复位，避免"程序以为中键还按着"导致整段音高错。
