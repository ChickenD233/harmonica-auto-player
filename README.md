# MIDI 转游戏乐器演奏器

导入 MIDI 文件。程序把每个音变成琴键和修饰键，在游戏的乐器界面上自动演奏。

程序不认识具体哪一款游戏。乐器键位写在「方案」里。换游戏就换方案。
内置方案覆盖常见的 7 / 14 / 15 / 21 键布局。没有合适的方案，就自己改一套。

- 系统：Windows 10 / 11（64 位）
- 单文件 exe。不需要安装 .NET
- 界面语言：中文

> ⚠️ 虚拟输入可能违反游戏规则，有封号风险。
> 请只在练习、单人、自定义房间场景使用。后果由使用者承担。

## 下载

1. 打开右侧 **Releases**。
2. 下载 `GameInstrumentPlayer-win-x64.zip`。当前版本 v2.0.0。
3. 解压。双击 `GameInstrumentPlayer.exe`。
4. 系统弹出 UAC，选「是」。
5. 如果弹出 SmartScreen「未知发布者」，选「更多信息」。然后选「仍要运行」。
6. 杀毒软件可能误报「模拟按键」。请把它加入白名单。

## 三步开始

1. **选乐器方案**。在右上方选一个和你游戏乐器一致的方案。
   没有合适的就点「新建」，按游戏里的键位改好，再点「保存方案」。
2. **打开 MIDI**。点「打开 MIDI 文件…」。绿点是推荐的主旋律轨，点其它行可以换。
3. **开始演奏**。点「一键移调」让所有音落进方案音域，再点「▶ 演奏」或按 **F6**。
   在倒计时结束前切到游戏，打开乐器。

## 乐器方案

方案决定三件事：

- 一行有几个琴键
- 每个位置是什么键
- 升半音（# 音）怎么按

内置 7 套方案：

| 方案 | 布局 | 升半音 |
|---|---|---|
| 三行 21 键（默认） | Z-M / A-J / Q-U | 按左 Shift |
| 三行 21 键 · 无升半音 | Z-M / A-J / Q-U | 自动降到最近的音 |
| 三行 21 键 · 升半音 = 换行 | Z-M / A-J / Q-U | 换到相邻八度行 |
| 两行 15 键 | Z-M / Q-U | 按左 Shift |
| 两行 14 键 · 无升半音 | Z-M / Q-U | 自动降到最近的音 |
| 单行 7 键 | Z-M | 自动降到最近的音 |
| 10 键 | Z-M + Q W E | 按左 Shift |

方案的名字只写键位和音域，不绑定具体游戏。同一个布局可能对应多款游戏。

### 改一套自己的方案

1. 在右上角选中一个最接近的方案。
2. 点「编辑键位…」。
3. 在「键位」页改每行键数、基准音高、每个格子的键。
4. 在「输出与时序」页选输出方式。必要时加大按键时序。
5. 点「试按键」，确认游戏收得到。
6. 点「保存方案」。内置方案不受影响，改动存成你自己的方案。

「试按键」需要游戏窗口在前台。点之前先切到游戏。

### 升半音四种处理方式

| 方式 | 什么时候用 |
|---|---|
| 同时按修饰键 | 先按修饰键，再按琴键。多数游戏的乐器用这种 |
| 换到相邻八度行 | 半音放在另一行的乐器 |
| 自动降到最近的音级 | 乐器只有自然音，例如竖琴 |
| 跳过这个音 | 直接空拍 |

### 输出方式

| 方式 | 什么时候用 |
|---|---|
| 键盘扫描码（推荐） | 绝大多数游戏与 DirectInput |
| 键盘虚拟键码 | 少数只认虚拟键码的游戏 |

修饰键和琴键都能设成鼠标键：左键、中键、右键、两个侧键。

### 方案文件

方案存成 JSON，放在：

```
%LOCALAPPDATA%\GameInstrumentPlayer\profiles\
```

点「导出…」把方案发给别人。对方点「导入…」读回来。

## 用法

1. 点「打开 MIDI 文件…」。选 `.mid`、`.midi`、`.kar` 或 `.rmi` 文件。
   可以先用 `示例MIDI/` 里的文件试手。
2. 在左侧点一行，作为主旋律。绿点是程序推荐的行。打击乐轨不能选。
3. 调速度、移调、倒计时。
4. 在卷帘或进度条上点一下，或拖动。右侧显示定位处的音。
5. 点「▶ 演奏」，或按 **F6**。
6. 在倒计时结束前切到游戏。打开乐器。

演奏中，你可以拖卷帘或进度条跳转。也可以实时改速度和移调。
暂停时可以直接打开另一首换歌。
演奏结束，点「停止」，或关闭窗口。程序把焦点还给游戏，并补发一次全部松开。

### 一键移调

点「一键移调」。程序搜索 ±12 半音，找出让空拍最少的移调量。
换方案之后要重新点一次。

## 卷帘编辑

卷帘画出整首旋律。绿条可演奏，灰条超出音域。你可以在上面直接改谱。

| 操作 | 结果 |
|---|---|
| 点空白 | 定位演奏位置 |
| 双击空白 | 在该时刻、该音高加一个音 |
| 拖动音符 | 移动。左右改时间，上下改音高 |
| 拖音符右缘 | 改长度 |
| 右键点音符 | 删除 |
| Delete 键 | 删除选中的音 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 勾选「吸附 0.1s」 | 拖动与加音按 0.1 秒对齐 |
| 滚轮 | 缩放时间轴 |
| Shift+滚轮 | 左右平移 |
| 中键拖动 | 左右平移 |
| 缩小 / 放大 / 全曲 | 工具栏按钮 |

整首歌挤进几百像素时，一个音只有 1 到 2 像素宽。先放大再编辑。

加音的长度取自当前谱面的中位音长。

改动只存在内存里。要留档，点「导出 MIDI…」。程序写出一个标准 MIDI 文件。
点「还原为自动」回到自动提取的结果。手动改动全部丢弃。

**换轨会丢改动。** 切换主旋律轨，或改合奏勾选，程序会丢弃手动改动。日志里会写明。
想保住改动，先导出 MIDI。

## 导出按键表

不想让本程序常驻，就导出按键脚本。三种格式：

| 格式 | 用法 |
|---|---|
| AutoHotkey 脚本 (.ahk) | 装好 AutoHotkey，双击运行。按 F8 开始，F9 退出 |
| 罗技 G HUB 脚本 (.lua) | G HUB → 设备 → 游戏与应用程序 → 添加游戏 → 编写脚本 → 整段粘贴 |
| 通用 CSV (.csv) | 时刻表。交给其它工具 |

导出的按键时序与实际演奏完全一致。

## 热键

程序用系统低层键盘钩子。热键在游戏中直接生效。

| 键 | 动作 |
|---|---|
| **F6** | 空闲=开始。演奏中=暂停。暂停中=继续。倒计时中=取消 |
| **F5** | 后退 5 秒 |
| **F7** | 前进 5 秒 |

三个键都能改，也能关掉。在界面的「控制热键」「后退热键」「前进热键」里改。

**注意**：演奏中跳转可能让游戏侧乐器卡音。遇到卡音，按「停止」，再重新开始。
最稳的用法是演奏前定位。

## 输入兼容

游戏按帧读按键。修饰键与琴键的间隔太短，会被折进同一帧，导致漏音。
「输入兼容」给时间余量：

| 档位 | 什么时候用 |
|---|---|
| 稳健 | 30fps、掉帧、机器负载高 |
| 方案默认 | 按当前方案的数值。推荐先试这个 |
| 极限 | 高帧率，要跟很快的歌 |

还漏音就打开「编辑键位…」，在「输出与时序」页加大「修饰键提前」和「按住最短」。

## 注意

1. 游戏用**窗口化**或**无边框窗口化**。全屏独占收不到模拟按键。
2. 演奏开始前，点一下游戏画面。游戏必须在前台。
3. 输入法切到**英文**。中文输入法会截走按键。
4. 游戏内**原地不动**。按住 `W`、`A`、`S`、`D` 时，键盘矩阵会吞掉部分琴键。
   这是键盘硬件限制，软件无法修复。只有全键无冲（NKRO）键盘可以避免。
5. 程序强制以管理员启动。游戏以管理员运行时，本程序也必须是管理员。否则 Windows 拦截按键。

## 适配一款新游戏

1. 在游戏里打开乐器，把琴键界面截图。或者看游戏设置里的键位说明。
2. 数一行有几个键，最低音是什么。
3. 在方案编辑器里按实际位置改每个格子。一行 = 一个八度。
4. 点「试按键」确认游戏收得到。
5. 保存方案，导出 JSON 分享给别人。

多数游戏的乐器按同一个规律排键：主键盘区分几行，一行一个八度。

## 自检

仓库带一个纯逻辑测试台，检查音高定位、四种升半音方式、音域空拍与方案读写。
不需要 Windows，也不需要图形界面。

```bash
dotnet run -c Release --project .tools/maptest
```

全部通过时最后一行输出「全部通过。」。

## 从源码构建

需要 .NET 8 SDK。在非 Windows 主机上交叉编译 Windows x64 单文件程序：

```bash
cd GameInstrumentPlayer
./build-win.sh
```

产物：`release/GameInstrumentPlayer-win-x64.zip`。

## 项目结构

```
GameInstrumentPlayer/
  Profiles/            乐器方案：模型、内置预设、JSON 读写
  Engine/              映射、演奏调度、时序、导出、自动更新
  Input/               键鼠输出、全局热键、演奏前自检
  Midi/                MIDI 解析与音符模型
  Controls/PianoRoll   卷帘编辑器
  MainWindow           主界面
  ProfileEditorWindow  方案编辑器
```
